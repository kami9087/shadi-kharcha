# Shadi Kharcha

Shadi ka kharcha tracker + customizable menu planner. Single-page app, data browser (localStorage) mein save hota hai.

## GitHub Pages par chalane ka tareeqa
1. GitHub par naya repo banayen (e.g. `shadi-kharcha`).
2. Is folder ki saari files repo mein upload karein.
3. Settings > Pages > Source: `Deploy from a branch` > `main` / `(root)` > Save.
4. Kuch minute baad link: `https://<username>.github.io/shadi-kharcha/`
5. Phone mein link kholkar "Add to Home Screen" karein.
